### How to Contribute

1. **Fork the Repository**
   ```bash
   # Fork on GitHub, then clone your fork
   git clone https://github.com/Dimah-code/python-mini-projects.git
   ```

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-project
   ```

3. **Add Your Project**
   ```bash
   # Create project directory
   mkdir -p new-category/your-project-name
   
   # Add your code and README
   # Include requirements.txt if needed
   ```

4. **Submit Pull Request**
   ```bash
   git add .
   git commit -m "Add amazing new project: Your Project Name"
   git push origin feature/amazing-project
   ```

### Project Requirements
- ✅ Clear, documented code
- ✅ README with usage instructions
- ✅ Error handling where appropriate
- ✅ Example input/output
- ✅ Requirements file if external dependencies

### Contribution Ideas
- 🆕 New mini-projects in any category
- 🔧 Improvements to existing projects
- 🐛 Bug fixes and optimizations
- 📚 Documentation enhancements
- 🎨 UI/UX improvements for GUI projects
